# 📊 Financial Dashboard in Excel

An interactive Financial Dashboard built in Microsoft Excel to analyze a company's financial performance using Profit & Loss, Balance Sheet, Cash Flow, Financial Ratios, and Risk Analysis. The dashboard provides key business insights through dynamic visualizations and KPI tracking.

---

## 🚀 Project Overview

This project demonstrates how Microsoft Excel can be used as a Business Intelligence tool to transform raw financial data into meaningful insights. It includes interactive dashboards, financial statement analysis, ratio calculations, and risk metrics to support data-driven decision making.

---

## ✨ Features

- 📈 Interactive Executive Dashboard
- 💰 Profit & Loss Analysis
- 🏦 Balance Sheet Analysis
- 💵 Cash Flow Analysis
- 📊 Financial Ratio Analysis
- ⚠️ Risk Dashboard
- 📅 Quarterly Performance Analysis
- 👥 Shareholding Pattern Analysis
- 🎯 KPI Tracking
- 📉 Dynamic Charts & Visualizations
