# 📊 Patel Engineering Financial Dashboard

> **Advanced Microsoft Excel-based Business Intelligence Solution for Financial Analytics & Performance Tracking**

An interactive and comprehensive Financial Dashboard built in Microsoft Excel to provide real-time analysis of Patel Engineering's financial performance. This professional-grade dashboard transforms complex financial data into actionable insights through interactive visualizations, KPI tracking, and multi-dimensional analysis.

---

## 🎯 Executive Summary

This project showcases enterprise-level financial analytics capabilities using Microsoft Excel as a Business Intelligence tool. The dashboard enables stakeholders to make data-driven decisions through interactive reports covering profit margins, asset management, cash flow optimization, and financial ratio analysis.

**Key Capabilities:**
- Real-time financial performance monitoring
- Multi-level drill-down analysis
- Automated KPI calculation and tracking
- Risk assessment and financial health scoring
- Interactive filtering and dynamic reporting

## 🚀 Getting Started

### Prerequisites
- Microsoft Excel 2016 or later (Excel 365 recommended)
- 50+ MB free disk space
- Basic understanding of Excel pivot tables

### Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/abhishekpandeyy555-commits/patel-engineering-financial-dashboard.git
   cd patel-engineering-financial-dashboard
   ```

2. **Open the Dashboard**
   - Double-click `Patel_Engineering_Finance_Dashboard.xlsx`
   - Enable macros if prompted (for enhanced interactivity)

3. **Load Data**
   - Place updated CSV files in the `data/` folder
   - Right-click on pivot tables and select "Refresh"
   - Or use Data → Refresh All

4. **Customize**
   - Update company name in headers
   - Modify color scheme in format cells
   - Adjust date ranges as needed

## 📊 Key Metrics & KPIs

The dashboard tracks the following critical metrics:

| Metric | Formula | Target |
|--------|---------|--------|
| **Gross Profit Margin** | (Revenue - COGS) / Revenue | >40% |
| **Operating Margin** | Operating Income / Revenue | >15% |
| **Net Profit Margin** | Net Income / Revenue | >10% |
| **Return on Assets (ROA)** | Net Income / Total Assets | >8% |
| **Return on Equity (ROE)** | Net Income / Shareholders' Equity | >15% |
| **Current Ratio** | Current Assets / Current Liabilities | 1.5-2.0 |
| **Debt-to-Equity** | Total Liabilities / Shareholders' Equity | <1.5 |
| **Interest Coverage** | EBIT / Interest Expense | >5x |

3. Go to **Data** tab → **Refresh All**
4. Alternatively, right-click on any pivot table and select **Refresh**

## 🆘 Support & Troubleshooting

### Common Issues

**Q: Pivot tables show "0" values**
- A: Ensure data sources are properly loaded and formatted

**Q: Charts not updating**
- A: Right-click chart → Edit Data → Refresh data range

**Q: Slicers not working**
- A: Verify slicer is connected to correct pivot table (Slicer Tools → Report Connections)

**Q: File is slow**
- A: Archive old data, optimize pivot table size, or split into multiple workbooks
